# CRM

Copy `prospects.template.csv` to `prospects.csv` and work in a spreadsheet. `prospects.csv` is
gitignored on purpose — it holds personal data of identifiable people.

**Do not build a CRM.** See [../../docs/roadmap.md](../../docs/roadmap.md) Gate 1.

Rules:
- Record support minutes per customer once they convert — that feeds the one metric that matters.
- Honour opt-outs immediately and permanently.
- The privacy policy must describe this processing before the first email goes out.
